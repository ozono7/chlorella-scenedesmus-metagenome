# chlorella-scenedesmus-metagenome

Code and data for the article "Metagenomic characterization of *Chlorella vulgaris* and *Scenedesmus acutus* consortia: bacterial metagenome-assembled genomes, shared metabolic pathways and machine-learning prioritization of microalga–bacteria interactions" (Algal Research, in preparation).

- `figuras_abner.R`: R script that generates the article figures from the CSVs.
- `datos_*.csv`: values as reported in the analysis of Abner Martínez-Constantino (FCQ-UASLP, August 2026).
- Raw sequencing reads and MAG assemblies will be deposited in SRA/GenBank; accessions pending.

For information or additional data, contact the corresponding author: Ruth Elena Soria-Guerra (ruth.soria@uaslp.mx).
